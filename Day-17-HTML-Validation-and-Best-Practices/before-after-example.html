Before and After: HTML Quality Improvement

BEFORE - Poor HTML

<div>
  <div>Title</div>
  <div>
    <div>Content here</div>
    <img src="image.jpg">
    <input type="text">
  </div>
</div>

AFTER - Good HTML

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Page Title</title>
</head>
<body>
    <header>
        <h1>Title</h1>
    </header>
    
    <main>
        <p>Content here</p>
        <img src="image.jpg" alt="Descriptive alternative text">
        
        <label for="username">Username:</label>
        <input type="text" id="username" name="username">
    </main>
</body>
</html>

Improvements Made

  • Added proper DOCTYPE and html structure
  • Used semantic elements (header, main) instead of divs
  • Added meta tags for charset and viewport
  • Added meaningful title
  • Added alt text for image
  • Associated label with input using for and id
  • Proper indentation and formatting
