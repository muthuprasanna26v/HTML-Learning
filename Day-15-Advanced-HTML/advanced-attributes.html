Advanced Attributes Summary

  • download - Forces download instead of navigation
  • contenteditable - Makes element editable
  • spellcheck - Enables/disables spell checking
  • draggable - Makes element draggable
  • autocomplete - Controls form autocomplete
  • readonly - Field is read-only but focusable
  • disabled - Field is disabled and not focusable
  • multiple - Allows multiple values
  • pattern - Regex pattern for validation
