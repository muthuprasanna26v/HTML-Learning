Meta Description Best Practices

What is a Meta Description?

A meta description is a short summary of a page's content that appears in search engine results.

Length Guidelines

Optimal length: 150-160 characters

Maximum: 160 characters (may be truncated beyond this)

Good Meta Description Example

Example: "Learn HTML from scratch with our comprehensive beginner's guide. Covers basics, elements, tags, and practical examples to start building websites today."

Bad Meta Description Example

Example: "This is a page about HTML. It has information. Click here to read more."

Best Practices

  • Include primary keywords naturally
  • Write compelling copy that encourages clicks
  • Match the page content accurately
  • Include a call-to-action when appropriate
  • Make each page's meta description unique
  • Avoid keyword stuffing

Important Note

Meta descriptions do not directly affect rankings, but they influence click-through rates which can impact SEO performance.
