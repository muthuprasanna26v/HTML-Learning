SEO Head Elements

Title Tag

The title tag is one of the most important SEO elements. It should be:

  • Descriptive and accurate
  • 50-60 characters long
  • Include primary keywords
  • Unique for each page

Meta Description

The meta description appears in search results. Best practices:

  • 150-160 characters long
  • Compelling and relevant
  • Include keywords naturally
  • Encourage clicks

Canonical URL

The canonical tag prevents duplicate content issues by specifying the preferred version of a page.

Language Attribute

The lang attribute on the html tag helps search engines understand the page language.
