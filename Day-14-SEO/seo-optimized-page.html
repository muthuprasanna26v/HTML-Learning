Introduction to HTML

HTML (HyperText Markup Language) is the foundation of web development. It defines the structure and content of web pages.

HTML Basics

HTML uses tags to define elements. Tags usually come in pairs: opening and closing tags.

Example: <p>This is a paragraph</p>

HTML Document Structure

An HTML document consists of DOCTYPE, html, head, and body elements.

The head contains meta-information, while the body contains visible content.

Common HTML Elements

Headings

Use h1 for the main title, h2 for section headings, and so on.

Paragraphs

Use p tags for paragraphs of text.

Links

Use a tags with href attribute for links.
