HTML Entities

What are HTML Entities?

HTML entities are used to display reserved characters and special characters that have special meaning in HTML.

Common HTML Entities

Character Entity Name Entity Number Description
< &lt; &#60; Less than
> &gt; &#62; Greater than
& &amp; &#38; Ampersand
" &quot; &#34; Double quote
' &apos; &#39; Single quote (apostrophe)
  &nbsp; &#160; Non-breaking space

Why Use Entities?

Some characters have special meaning in HTML and cannot be used directly in text.

Example: To display <p> as text, use &lt;p&gt;
