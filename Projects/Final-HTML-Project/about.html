About Me

I'm a full stack web developer with over 7 years of experience creating accessible, performant, and user-friendly web applications. My passion lies in building digital experiences that work for everyone, regardless of ability or device.

My journey in web development began with a curiosity about how websites work and a desire to make the internet more accessible. Since then, I've worked with startups, agencies, and enterprise companies, always advocating for inclusive design and best practices.

I believe that great web development is about more than just writing code—it's about understanding users, solving real problems, and creating experiences that make a positive impact.

My Philosophy

Accessibility First

I believe the web should be accessible to everyone. I build with accessibility in mind from the start, ensuring semantic HTML, proper ARIA attributes, and keyboard navigation support.

Performance Matters

Fast websites provide better user experiences and improve SEO. I optimize for performance through efficient code, optimized assets, and modern techniques.

Semantic & Clean Code

Clean, semantic code is easier to maintain, more accessible, and better for SEO. I follow best practices and write code that others can understand and build upon.

User-Centered Design

Every decision I make is guided by user needs. I advocate for user testing, feedback loops, and iterative improvement.
