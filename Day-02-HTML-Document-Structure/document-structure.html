Complete HTML Document Structure

Head vs Body

The head contains meta-information (not displayed)

The body contains visible content

What Goes in Head?

  • Title tag
  • Meta tags
  • Style tags (for CSS)
  • Script tags (for JavaScript)
  • Link tags (for external resources)

What Goes in Body?

  • Headings (h1-h6)
  • Paragraphs
  • Images
  • Links
  • Lists
  • Tables
  • Forms
  • All visible content

Language Attribute

The lang attribute on the html tag specifies the language: <html lang="en">

Charset

<meta charset="UTF-8"> ensures proper character display

Viewport

<meta name="viewport" content="width=device-width, initial-scale=1.0"> ensures responsive design
