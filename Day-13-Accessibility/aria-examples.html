ARIA Best Practices

  • Use native HTML semantics first
  • Only use ARIA when necessary
  • Don't override native semantics
  • Test with screen readers
  • Use aria-live for dynamic content
  • Use aria-label for icon-only buttons

Important Note

First rule of ARIA: If you can use a native HTML element with built-in semantics and behavior, do that instead of using ARIA.
